# افزونه حمایت مالی زیبال - نسخه 2.0

پلاگین حمایت مالی برای وردپرس با درگاه پرداخت زیبال

## نصب و راه‌اندازی

1. پوشه `zibal-wordpress-donate-master` را در مسیر `/wp-content/plugins/` آپلود کنید
2. افزونه را از طریق منوی 'افزونه‌ها' در وردپرس فعال کنید
3. به منوی 'حمایت مالی زیبال' بروید و تنظیمات را انجام دهید
4. کد درگاه پرداخت خود را وارد کنید
5. از shortcode `[ZibalDonate]` استفاده کنید

## استفاده از Shortcode

### استفاده ساده
```
[ZibalDonate]
```

### استفاده پیشرفته
```
[ZibalDonate 
    title="حمایت از پروژه" 
    description="از پروژه ما حمایت کنید" 
    min_amount="5000" 
    max_amount="1000000"
    required_fields="name,amount,mobile"
    button_text="حمایت کنید"
]
```

## پارامترهای Shortcode

| پارامتر | پیش‌فرض | توضیحات |
|---------|---------|---------|
| `title` | "حمایت مالی" | عنوان فرم |
| `description` | - | توضیحات فرم |
| `min_amount` | 1000 | حداقل مبلغ (ریال) |
| `max_amount` | 50000000 | حداکثر مبلغ (ریال) |
| `required_fields` | "name,amount" | فیلدهای اجباری |
| `show_description` | "true" | نمایش فیلد توضیحات |
| `button_text` | "پرداخت" | متن دکمه |

## فیلدهای قابل استفاده در required_fields

- `name` - نام و نام خانوادگی
- `amount` - مبلغ
- `mobile` - شماره موبایل
- `email` - ایمیل
- `description` - توضیحات
